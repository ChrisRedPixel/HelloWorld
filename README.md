# HelloWorld

My first C# console application.

This project demonstrates how to create, build, run, and publish a simple
.NET application using VS Code, Git, and GitHub.

> This project is intended for learning and practice.

## Description

HelloWorld is a simple C# console application created as an introduction to
.NET development.

The project also demonstrates basic Git and GitHub workflow, including
cloning, committing, and pushing changes.

## Requirements

- Development Tools
- .NET SDK
- VS Code
- Source Control
- Git
- GitHub account

## Getting Started

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run `dotnet build`.
4. Run `dotnet run --project "src/HelloWorld"`.

## Usage

Debug the application by Run > Start Debugging (or press F5).

Expected output:

```text
Hello, World!
```
## Example Code

```csharp
Console.WriteLine("Hello, World!");
```
